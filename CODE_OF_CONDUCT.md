# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be specific, assume good faith. Harassment, personal
attacks and discrimination are not tolerated in issues, discussions, pull
requests or anywhere else connected to the project. Report problems to the
maintainer at the address on the GitHub profile; reports are handled
privately.

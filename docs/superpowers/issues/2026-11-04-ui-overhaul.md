# UI 개편 이슈 초안

설계: [2026-11-04-ui-design-system-design.md](../specs/2026-11-04-ui-design-system-design.md).
번호 순서대로 처리한다. 각 이슈는 PR 하나이고, 끝날 때마다
`npm run typecheck && npm test`가 통과해야 한다.

## 1. (#10) Svelte와 `src/ui` 뼈대

- 라벨: chore, accepted
- 불편: 패널 모듈이 HTML 문자열을 직접 만들고, 화면을 갱신하는 방식이 모듈마다 다르다.
- 할 일:
  - `esbuild-svelte`와 Svelte 5를 `build.mjs`에 붙인다.
  - `src/ui` 진입점을 만든다.
  - 레이어 검사기가 `.svelte`의 `<script>`도 읽게 한다.
  - THIRD_PARTY_NOTICES.md에 추가한다.
- 끝: 빈 Svelte 컴포넌트 하나가 지금 패널 안에 뜨고, CSP 위반이 없다.

## 2. (#11) 디자인 토큰과 공용 부품

- 라벨: enhancement, design
- 불편: 색·간격이 `styles.css` 25KB에 섞여 있고, 글자 크기 10·14px과 그림자
  1~4px이 제각각이다.
- 할 일:
  - 토큰을 TS로 정의하고 CSS 변수로 내보낸다. 색 값은 그대로 둔다.
  - 공용 부품을 만든다: 버튼, 아이콘 버튼, 묶음 탭, 작은 탭, 카드, 입력칸,
    체크박스, 진행 막대, 빈 상태, 위젯 틀.
- 끝: 부품 견본 화면 하나를 만들고, 전후 스크린샷을 남긴다.
- 선행: #10

## 3. (#12) 패널 셸: 큰 묶음 + 작은 탭, 모듈 등록

- 라벨: enhancement, design
- 불편: 탭 9개가 넘쳐 글자가 겹치고, "나가기"가 탭처럼 보인다. 탭 목록은
  `renderer.ts`에 하드코딩돼 있다.
- 할 일:
  - 묶음을 홈 / 집중 / 기록 / (함께, 숨김) / ⚙로 나눈다.
  - 모듈 등록만으로 탭이 생기게 한다.
  - 옛 모듈은 어댑터로 끼운다.
  - "나가기"는 설정 맨 아래로 옮긴다.
  - 저장된 `ui.module` 값을 새 위치로 옮긴다.
- 끝: 모든 기존 기능을 새 묶음에서 열 수 있다.
- 선행: #11

## 4. (#13) 모듈 이전 (모듈 하나에 PR 하나)

- 라벨: chore
- 순서: 할 일 → 뽀모도로 → 메모 → 대시보드 → 음악 → 설정(+캐릭터·친구·백업)
  → 대화(기록 묶음)
- 각 모듈마다:
  - 계산은 순수 함수로 빼고 테스트를 붙인다.
  - IME·Enter를 확인한다.
  - 전후 스크린샷을 비교한다.
- 선행: #12

## 5. (#14) 위젯 시스템과 홈 보드

- 라벨: feature
- 할 일:
  - 위젯 틀과 위젯 등록을 만든다.
  - 홈 보드 격자에서 위젯을 추가·제거하고 순서를 바꿀 수 있게 하고, 배치를
    kv에 저장한다.
  - 첫 위젯: 타이머, 할 일 요약, 고정 메모, 음악.
  - 위젯의 데이터 출처를 가리지 않게 한다(나중에 "남의 뽀모도로" 위젯이 들어올 수 있게).
- 선행: #13의 할 일·뽀모도로·메모·음악

## 6. (#15) 픽셀 플립 탁상시계 위젯

- 라벨: feature, design
- 할 일:
  - 보라 몸체에 시·분 숫자판 두 장을 둔다.
  - 분이 바뀔 때 판이 넘어간다.
  - reduced motion이면 넘기지 않는다.
- 선행: #14

## 7. (#16) 옆 도크

- 라벨: enhancement, design
- 불편:
  - 말 걸기 버튼이 어깨 위에 숨어 있어서 마우스를 올려야 보이고, 쓰다듬기와 부딪친다.
  - 위젯을 놓을 자리가 없다.
- 할 일:
  - 💬 버튼과 위젯(최대 3개)을 펫 옆 한 줄에 둔다.
  - 도크는 친구 펫이나 화면 가장자리의 반대쪽에 붙는다.
  - 마우스가 도크 위에 있으면 걷기를 멈춘다.
  - 패널이 열리면 도크를 숨긴다.
  - 음악 재생 띠를 도크의 음악 위젯으로 바꾼다.
- 끝: 도크 쪽 고르기를 순수 함수로 만들고 테스트한다.
- 선행: #14

## 8. (#17) 트레이 메뉴와 대화 단축키

- 라벨: feature
- 불편: 나가기가 탭에서 빠지면 앱을 끄는 길이 설정 하나뿐이다. 단축키를
  모르면 쓸 수 없는 기능이 있다.
- 할 일:
  - 트레이에 패널 열기, 말 걸기, 위치 초기화, 나가기를 둔다.
  - 대화 단축키 ⌘/Ctrl+Alt+C를 설정에서 켜게 한다(기본 꺼짐).
- 선행: #12

## 9. (#18) 대화 탭 스트리밍 표시

- 라벨: bug
- 불편: delta마다 목록 전체를 다시 그리고 맨 아래로 끌어내려서, 답이 오는 동안
  위로 올려 읽을 수 없다.
- 할 일:
  - 진행 중인 답만 이어 쓰고, 프레임당 한 번만 그린다.
  - 맨 아래 근처일 때만 따라 내려간다. 아니면 "새 메시지 ↓"를 띄운다.
- 선행: #13의 대화

## 10. (#19) 말풍선: 말하듯 스트리밍, 긴 답 "더 보기"

- 라벨: enhancement
- 불편: 말풍선은 끝날 때까지 "생각 중"이다가 120자로 잘린 글을 10초 보여 준다.
  나머지는 볼 길이 없다.
- 할 일:
  - 답을 문장 단위로 타자 치듯 보여 준다.
  - 최대 3줄까지 보여 주고, 넘치면 "더 보기 ▸"로 대화 탭을 연다.
  - 마크다운 기호는 지운다.
- 선행: #18

## 11. (#20) 대화 탭 마크다운 일부 지원

- 라벨: enhancement
- 불편: 모델이 쓴 `**굵게**`나 `- 목록`이 기호 그대로 보인다.
- 할 일:
  - 굵게, 기울임, 인라인 코드, 목록, 줄바꿈, 코드 블록(복사 버튼)을 지원한다.
  - 링크는 외부로 열기 전에 묻는다.
  - 출력은 이스케이프된 상태에서 시작하고, 스트리밍 중 닫히지 않은 표시는
    평문으로 둔다.
- 선행: #18

# UI 디자인 시스템과 모듈화 설계

날짜: 2026-11-04 · 상태: 사용자 검토 대기

## 왜 하는가

패널 UI가 아쉽다. 탭 9개(할 일, 뽀모도로, 대시보드, 음악, 메모, 대화, 캐릭터,
설정, 나가기)가 한 줄에 들어가 글자가 겹치고, "나가기"까지 탭처럼 보인다. 한 번에
탭 하나만 보여서 할 일을 보며 타이머를 볼 수 없다. 코드도 `src/renderer/modules/*`의
`PanelModule`이 HTML 문자열을 직접 만들고, 탭 목록은 `renderer.ts`에 하드코딩돼 있고,
색·간격이 `styles.css`(25KB) 한 파일에 섞여 있다.

사용자는 지금의 분위기(짙은 보라 바탕, 분홍·주황 포인트, Galmuri 픽셀 폰트)는
살리되 **체계적으로 정리**하고, **코드를 제대로 모듈화**하기를 원한다.

## 이 문서의 범위

사용자가 요청한 전체 작업은 여섯 개의 독립 프로젝트다. 이 문서는 1과 2만 다룬다.

1. **디자인 시스템 + 패널 구조** ← 이 문서
2. **코드 모듈화 (Svelte, `src/ui`)** ← 이 문서
3. 각 모듈 개선, 시계·노트 위젯 확장
4. 환경설정 정리
5. LLM 대화 품질 (캐릭터끼리 나누는 대화가 이상하다는 문제)
6. 원격/멀티플레이 (아래 "나중 프로젝트에 넘기는 결정" 참고)

## 목표

- **디자인 토큰:** 색, 글자, 간격, 테두리, 그림자, 움직임을 한곳에 정의한다. 지금
  `styles.css`의 `:root` 변수(`--ink`, `--panel`, `--well`, `--edge`, `--focus`,
  `--break`, `--long`, `--goal`, `--heat-*`, Galmuri 글꼴 세 가지)가 출발점이다.
  색 값은 바꾸지 않고 이름과 단계를 정리한다.
- **공용 부품:** 버튼, 아이콘 버튼, 묶음 탭, 작은 탭(세그먼트), 카드, 입력칸,
  체크박스, 진행 막대, 빈 상태, 위젯 틀. 모듈은 이 부품과 토큰만 쓴다.
- **패널 구조: 큰 묶음 + 작은 탭.** 위에는 큰 묶음만 두고, 안에서 작은 탭으로 나눈다.

  | 묶음 | 안에 있는 것 |
  | --- | --- |
  | 홈 | 위젯 보드 |
  | 집중 | 할 일 · 뽀모도로 · 음악 |
  | 기록 | 메모 · 대시보드 · 대화 기록 |
  | 함께 | 멀티플레이 (프로젝트 6에서 채움) |
  | ⚙ | 설정 · 캐릭터/친구 · 백업 · 나가기 |

- **대화는 펫 옆 💬 버튼 한 번으로 연다.** 탭에서 빼고, 지난 대화와 크게 보기는
  기록 묶음에서 한다. 아래 "펫 곁 상호작용" 참고.
- **"나가기"는 탭이 아니다.** 설정 맨 아래와 새 트레이 메뉴에 둔다.
- **위젯 시스템:** 위젯은 하나의 부품을 두 곳에서 쓴다.
  - 홈 묶음의 **위젯 보드**(카드 격자. 추가·제거·순서 바꾸기 가능)
  - 패널이 닫혔을 때 **펫 옆 도크**에 띄우는 작은 위젯
  - 위젯마다 보드에 둘지, 도크에 둘지, 둘 다 둘지 사용자가 고른다.
- **첫 위젯 묶음:** 시계, 타이머(진행 중인 뽀모도로), 할 일 요약, 고정 메모, 음악.
  - **시계는 픽셀아트 플립 탁상시계**다. 사용자가 브레인스토밍 목업 B를 골랐다.
    보라 몸체에 어두운 숫자판 두 장(시·분)이 있고, 분이 바뀔 때 판이 넘어가는
    애니메이션이 있다.
    목업 위치: `.superpowers/brainstorm/*/content/desk-clock.html`.
  - 알람과 스톱워치는 프로젝트 3에서 다룬다.
- **Svelte로 옮기고 `src/ui` 레이어에 둔다.** 모듈 하나(탭 또는 위젯)가 자기
  컴포넌트, 스타일, 데이터 연결을 스스로 가진다. **등록**하면 묶음 탭과 위젯 보드에
  나타나고, `renderer.ts`에 손으로 목록을 적지 않는다.

## 펫 곁 상호작용 (사용자 승인)

지금 코드(`src/renderer/pet/input.ts`, `chatbar.ts`, `bubble.ts`, `friends.ts`,
`walking.ts`)의 모든 입력을 대조해서, 겹침 없이 모은 안이다. 목업:
`.superpowers/brainstorm/*/content/interaction-dock.html`.

- **입력 하나에 뜻 하나.** 지금과 같다.

  | 입력 | 동작 |
  | --- | --- |
  | 왼쪽 클릭 | 쓰다듬기 (부위 반응, 모드 tap, 하트) |
  | 드래그 | 옮기기 |
  | 오른쪽 클릭 / ContextMenu / Shift+F10 | 패널 열기·닫기 |
  | Enter / Space (펫에 초점) | 쓰다듬기 |
  | 말풍선 클릭 | 해금 닫기, 다음 대사 |

- **머리 위에는 말하는 것만 둔다.** 말풍선과 빠른 대화 입력창이다.
- **펫 옆에는 누르는 것만 둔다: "옆 도크".** 말 걸기 💬 버튼과 위젯(최대 3개)을
  펫 옆에 세로 한 줄로 쌓는다.
  - 말 걸기 버튼은 지금의 어깨 위 자리(`#chat-toggle`, 마우스를 올려야 보임)에서
    도크로 옮기고, 늘 보이게 한다. 몸 위에서 떨어지므로 쓰다듬기·드래그와 부딪치지
    않는다.
  - 위젯과 말풍선이 위아래로 쌓이지 않으므로 서로를 접거나 밀어낼 일이 없다.
- **도크는 남는 쪽에 붙는다.** 기본은 넓은 쪽이다. 친구 펫이 다가온 쪽
  (`friends.ts` `NEAR_X = 240`)이나 화면 가장자리(`petDx`)의 반대편으로 간다.
  창 너비 380px(`WINDOW_WIDTH`) 안에 들어가야 한다. 펫 폭은 약 156px이라 한쪽에
  약 110px이 남는다.
- **마우스가 도크 위에 있으면 걷기를 잠깐 멈춘다.** 움직이는 버튼을 누르지 않게 한다.
- **패널이 열리면 도크의 위젯을 숨긴다.** 같은 위젯이 홈 보드에 있다.
- **지금의 음악 재생 띠(`#player-strip`)가 도크의 음악 위젯이 된다.** 기본으로
  켜 두고, 음악 UI가 둘이 되지 않게 한다.
- **대화 단축키는 설정에서 켜는 선택 기능이다.** 기본 조합은 ⌘/Ctrl+Alt+C로,
  위치 초기화 키(⌘/Ctrl+Alt+P, `RESET_SHORTCUT`)와 짝을 맞춘다. 전역 단축키는
  다른 앱의 키를 빼앗으므로 기본은 꺼 둔다.
- **트레이(메뉴 막대) 메뉴를 새로 만든다.** 패널 열기, 말 걸기, 위치 초기화,
  나가기가 들어간다. 단축키가 있는 동작은 모두 트레이에도 있어서, 키를 몰라도 다
  쓸 수 있다. Electron `Tray`는 지금 `src/main`에 있는 창 코드 옆에 둔다.

## 채팅 표시 (스트리밍, 긴 답, 마크다운)

지금 상태(코드 확인):

- main은 답을 스트리밍한다(`chatAgent.ts`, `chat.ts`의 `delta`, 누적 텍스트).
- **대화 탭**은 delta마다 대화 목록 전체를 `innerHTML`로 다시 그리고 맨 아래로
  스크롤한다(`modules/chat.ts` `renderSession`). 그래서 답이 오는 동안 위로
  올려 읽으면 계속 아래로 끌려 내려간다.
- **말풍선**은 스트리밍하지 않는다. "음… 생각 중"을 띄우고, 답이 끝나면 120자로
  자른 글(`short`)을 10초 보여 준다. 긴 답은 "…"로 잘리고, 나머지를 보려면
  패널을 열어야 한다.
- **마크다운은 지원하지 않는다.** 글을 이스케이프해서 `pre-wrap`으로 보여 준다.
  프롬프트(`shared/chat.ts`)는 표나 긴 코드 블록을 피하라고만 해서, 모델이 쓴
  `**굵게**`나 `- 목록`이 기호 그대로 보인다.

이렇게 바꾼다:

- **대화 탭 스트리밍:**
  - 진행 중인 답 하나만 이어 쓴다. 프레임당 한 번만 그린다.
  - 사용자가 맨 아래 근처에 있을 때만 따라 내려간다. 위로 올려 읽는 중이면
    "새 메시지 ↓" 버튼을 띄운다.
  - 멈춤 버튼은 지금처럼 둔다.
- **말풍선은 말하듯이 보여 준다.**
  - 스트리밍되는 답을 문장이나 구 단위로 끊어서 타자 치듯 보여 준다. 토큰
    단위로 깜빡이지 않는다.
  - 말풍선은 최대 3줄까지 보여 준다. 더 길면 끝에 "더 보기 ▸"를 붙이고, 누르면
    기록 묶음의 대화 탭이 열린다.
  - 말풍선에서는 마크다운 기호를 지우고 평문으로 보여 준다.
- **대화 탭은 마크다운 일부만 지원한다:** 굵게, 기울임, 인라인 코드, 목록, 줄바꿈,
  코드 블록(GalmuriMono, 복사 버튼).
  - 표, 이미지, HTML, 수식은 지원하지 않는다.
  - 링크는 글자로만 보여 주고, 누르면 외부 브라우저로 열기 전에 묻는다.
  - 모든 출력은 이스케이프된 상태에서 시작한다.
  - 스트리밍 중 닫히지 않은 `**`나 ```` ``` ````는 닫힐 때까지 평문으로 둔다.
  - 구현은 작은 자체 파서를 권한다(빌더 판단). stickypane의 unified/remark
    체인은 이 범위에 비해 크다.

## 확인 방법 (사용자 승인)

패널 모듈(`src/renderer/modules/*`)에는 지금 테스트가 없다. 옮기면서 이렇게 확인한다.

- 모듈 안의 계산(할 일 정렬, 날짜 묶기, 시간 표시, 도크 쪽 고르기 등)은 순수
  함수로 빼고, 그 함수에 vitest 테스트를 붙인다.
- 한국어 IME와 Enter 처리처럼 깨지기 쉬운 곳만 작은 테스트를 둔다.
- 화면은 옮기기 전후에 `scripts/demo-shots.mjs`로 스크린샷을 찍어 나란히
  비교하고, 직접 눌러 본다. 이때 `PETNUDGE_PROFILE`은 임시 폴더로 둔다.
- 끝날 때마다 `npm run typecheck && npm test`가 통과해야 한다.

## 하지 않는 것

- 색이나 분위기를 새로 만드는 것. 정리만 한다.
- 각 모듈의 기능 개선. 옮기면서 동작은 그대로 둔다(프로젝트 3).
- 설정 항목을 다시 짜는 것(프로젝트 4). 설정 화면은 새 부품으로 옮기기만 한다.
- LLM 대화 품질(프로젝트 5)과 멀티플레이(프로젝트 6).
- 펫 그리기(캐릭터 합성, 걷기, 말풍선 위치 계산)를 Svelte 반응성으로 다시 쓰는 것.
  펫 캔버스 루프는 지금처럼 따로 돈다.

## 실패로 보는 것 (기술적으로 돌아가도)

- 기존 기능이 사라지거나 동작이 바뀌는 것. 테스트가 명세다.
- 펫 애니메이션이 끊기거나 CPU 사용이 늘어나는 것.
- 픽셀 느낌이 흐려지는 것: 안티에일리어싱된 글자, 둥근 모서리, 부드러운 그림자,
  1px이 아닌 배율.
- 한국어 IME 입력이 깨지는 것. Enter 처리에서 `isComposing`을 무시하면 안 된다.
- 묶음 탭이 다시 넘치는 것. 탭 글자가 겹치거나 잘리면 실패다.

## 제약

- **레이어 규칙**(AGENTS.md, `src/architecture.test.ts`): `ui`는 `ui`, `domain`,
  옛 폴더만 가져올 수 있다. electron, effect, `node:`는 쓸 수 없다. 지금 검사기는
  `.ts`만 읽는다.
- **CSP**(`src/renderer/index.html`): `script-src 'self'`, `style-src 'self'
  'unsafe-inline'`. 빌드 결과가 이 정책 안에서 돌아야 한다.
- **빌드**는 `build.mjs`(esbuild)다. 렌더러는 `iife` 번들이다. 묶여 들어가는
  패키지의 라이선스를 자동으로 `dist/licenses/`에 모으므로 Svelte도 여기에 잡혀야
  한다. 새 의존성은 THIRD_PARTY_NOTICES.md에 적는다.
- **창은 하나**이고 투명하며 항상 위에 있다. 패널이 열리고 닫힐 때 창 크기는
  `src/main/layout.ts`의 `computeLayout`이 정한다. 렌더러가 펫 영역 크기와 패널
  상태를 알려 준다. 옆 도크는 펫 옆에 놓이므로 창 높이는 그대로이고, 380px
  너비 안에서 자리를 잡는다.
- **IPC**는 지금 `api`(preload의 `petApi`)를 거친다. 이 경계는 이번에 바꾸지 않는다.
- **스크린샷과 실험**은 `PETNUDGE_PROFILE` 임시 폴더로만 한다.
  `scripts/demo-shots.mjs`가 그렇게 동작한다.
- **글꼴**은 Galmuri11, Galmuri9, GalmuriMono11이고 `-webkit-font-smoothing: none`을 쓴다.

## 정해진 것 (사용자 결정)

- 분위기는 유지하고 체계적으로 정리한다.
- 패널은 큰 묶음 + 작은 탭이다. 홈 묶음은 위젯 보드다.
- 예전 "펫" 묶음은 없앤다. 대화는 펫 클릭으로 열고, 지난 대화는 기록 묶음에 둔다.
- 위젯은 보드와 펫 옆 도크 양쪽에 놓을 수 있다.
- 펫 곁 상호작용은 "옆 도크" 안대로 한다(위 절).
- 확인 방법은 계산 로직 테스트와 전후 스크린샷이다(위 절).
- 시계는 픽셀아트 플립 탁상시계다.
- UI 프레임워크는 Svelte다.
- 모듈화는 코드 구조를 말한다. 사용자가 탭을 켜고 끄는 기능을 말하는 게 아니다.

## 내가 정한 것 (사용자 확인 전, 바꿀 수 있음)

- **점진 이전.** Svelte 패널을 먼저 세우고, 옛 모듈을 하나씩 옮긴다. 아직 안 옮긴
  모듈은 옛 `mount/render`를 감싸는 어댑터로 새 셸에 끼운다. 모듈 하나를 옮길
  때마다 테스트가 통과해야 한다.
- **토큰 형식.** stickypane 데스크톱(`../stickypane/desktop/frontend/src/lib/theme/`)
  처럼 TS로 정의하고 CSS 변수로 내보낸다. 크기는 4px 단위다. 글자 크기 단계는
  Galmuri의 비트맵 크기(9·11과 그 정수배)에 맞춘다.
- **음악은 집중 묶음에** 두고, 홈에는 음악 위젯을 둔다.
- **캐릭터/친구 설정은 ⚙ 안으로** 옮긴다.
- **함께 묶음은 프로젝트 6 전까지 숨긴다.**
- **도크 위젯의 개별 드래그 배치는 나중에** 한다. 지금은 도크 안 순서만 바꾼다.
- **위젯 배치는 kv에 저장한다.** 지금 `ui.module`을 `api.db.setKv`로 저장하듯이 한다.
- **레이어 검사기를 `.svelte`까지 넓힌다.** `<script>` 블록의 import도 검사한다.
- **크게 보는 대화창은 기록 묶음의 "대화" 탭이다.** 지난 대화 목록과 진행 중인
  대화를 함께 보여 준다. 빠른 대화 입력창(`pet/chatbar.ts`)의 "크게 보기"는 이
  탭을 연다.
- **토큰에 맞추면서 크기와 간격은 조금 달라져도 된다.** "체계적으로 정리"의
  뜻으로 봤다. 색 값은 그대로 둔다. 10px·14px 글자는 가장 가까운 단계로 맞추고,
  그림자는 2·4px 두 단계로 줄인다. 전후 스크린샷(`demo-shots`)을 나란히 남긴다.

## 나중 프로젝트에 넘기는 결정 (이번에 만들지 않음)

- **멀티플레이(6):**
  - 세션을 공유해서 서로의 펫을 풀어놓고 대화한다.
  - 남은 내 것을 바꿀 수 없다.

  - 상대가 집중 중인 뽀모도로는 위젯으로 띄울 수 있다.
  - Rust는 세션 서버에 쓸 수 있다.
  - 이번 위젯 시스템은 "남의 뽀모도로" 위젯이 나중에 들어갈 수 있게 데이터 출처를
    가리지 않아야 한다.

  찾는다. 실제 사용자 데이터라 어느 기록을 볼지는 그때 확인한다.

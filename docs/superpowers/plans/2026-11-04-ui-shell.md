# UI 뼈대·토큰·패널 셸 Implementation Plan (#10 · #11 · #12)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 렌더러에 Svelte를 들이고, `src/ui`에 디자인 토큰·공용 부품과 "큰 묶음 + 작은 탭" 패널 셸을 세워 옛 모듈 8개를 그대로 끼운다.

**Architecture:** esbuild 렌더러 번들에 `esbuild-svelte` 플러그인을 붙인다. `src/ui`는 토큰(TS → CSS 변수), 부품(.svelte), 패널 셸(묶음 정의는 순수 TS, 화면은 Svelte)을 가진다. 셸은 옛 `PanelModule`의 `mount/render`를 감싸서 한 번만 마운트한다. `renderer.ts`는 손으로 만든 탭 대신 셸 컨트롤러를 쓴다.

**Tech Stack:** Svelte 5, esbuild-svelte 0.9, esbuild 0.28, TypeScript 7, vitest 5, Electron 44.

**Spec:** `docs/superpowers/specs/2026-11-04-ui-design-system-design.md`

## Global Constraints

- 레이어: `src/ui`는 `ui`, `domain`, 옛 폴더(`renderer`, `shared`, `main`, `preload`)만 가져온다. `electron`, `effect`, `node:`는 안 된다. 테스트 파일도 같다.
- 색 값은 바꾸지 않는다. 지금 `src/renderer/styles.css` `:root`의 변수 이름도 계속 쓸 수 있어야 한다.
- 픽셀 느낌: `border-radius` 0, 안티에일리어싱 없음(`-webkit-font-smoothing: none`), 그림자는 2px·4px의 딱딱한 오프셋 그림자만 쓴다.
- 글꼴: Galmuri9(10px), Galmuri11(12px), GalmuriMono11(숫자).
- CSP `script-src 'self'; style-src 'self' 'unsafe-inline'`을 지킨다. 번들에 `eval(`이나 `new Function(`이 있으면 안 된다.
- 한국어 IME: Enter 처리에서 `event.isComposing`을 존중한다(`onEnter` 재사용).
- 실행과 스크린샷은 `PETNUDGE_PROFILE`을 임시 폴더로 둔다(`scripts/demo-shots.mjs`).
- 새 의존성은 THIRD_PARTY_NOTICES.md 표에 적는다.
- 커밋은 Conventional Commits로, 커밋 하나에 변경 하나만 담는다. AI 도구를 밝히는 트레일러는 넣지 않는다.
- 각 작업 끝에 `npm run typecheck && npm test`가 통과해야 한다.

## Review Focus

1. **묶음을 바꿔도 옛 모듈을 다시 마운트하지 않는다.** 할 일 입력칸에 한글을 치다가 묶음을 오가도 입력과 포커스 상태가 남아야 한다. → Task 4 Step 6 수동 확인
2. **저장된 `ui.module`이 없거나 모르는 값이면** 뽀모도로를 연다. 숨긴 묶음에 속한 값이어도 같다. → Task 3 테스트
3. **빠른 대화창의 "크게 보기"(`showModule('chat')`)는** 기록 묶음으로 넘어가서 대화 탭을 연다. → Task 3 `groupOf` 테스트 + Task 4 Step 6
4. **패널이 최소 높이 220px(`MIN_PANEL_HEIGHT`)로 줄어도** 묶음 줄과 작은 탭 줄은 그대로 보이고, 내용만 스크롤된다. → Task 4 Step 6
5. **키보드로만 다룰 수 있어야 한다.** 묶음 탭과 작은 탭 모두 ←/→/Home/End로 이동하고, 선택된 탭만 `tabIndex=0`이다. → Task 3 `step` 테스트

### Task 3: 묶음 정의와 탭 이동 (#12, 1/2)

**Files:**
- Create: `src/ui/panel/groups.ts`, `src/ui/panel/groups.test.ts`

**Interfaces:**
- Consumes: `ModuleId`(`src/renderer/modules/module.ts`)
- Produces:
  - `type GroupId = 'home' | 'focus' | 'record' | 'together' | 'settings'`
  - `GROUPS: readonly { id: GroupId; label: string; icon: PixelIconName; modules: ModuleId[]; hidden?: boolean }[]`
    - home: 홈, 위젯 보드는 #14에서 채운다. 그때까지 hidden이다.
    - focus: 집중, `['todo', 'pomodoro', 'playlist']`
    - record: 기록, `['notes', 'dashboard', 'chat']`
    - together: 함께, hidden
    - settings: ⚙(label '설정'), `['settings', 'friends']`
  - `visibleGroups(): typeof GROUPS`
  - `groupOf(id: ModuleId): GroupId`
  - `restoreModule(saved: string | null): ModuleId`: 보이는 묶음에 속한 값이면 그대로 돌려주고, 아니면 `'pomodoro'`를 돌려준다.
  - `step(ids: readonly string[], current: string, key: string): string | null`: ArrowLeft/Right는 순환하고, Home/End는 끝으로 간다. 다른 키는 `null`이다.

- [ ] **Step 1: 실패하는 테스트 쓰기**

```ts
it('puts every module in exactly one visible group', () => {
  const all = visibleGroups().flatMap((g) => g.modules);
  expect(new Set(all).size).toBe(all.length);
  expect([...all].sort()).toEqual(['chat', 'dashboard', 'friends', 'notes', 'playlist', 'pomodoro', 'settings', 'todo']);
});
it('opens the chat from the record group', () => expect(groupOf('chat')).toBe('record'));
it('restores a saved module or falls back to the pomodoro', () => {
  expect(restoreModule('notes')).toBe('notes');
  expect(restoreModule(null)).toBe('pomodoro');
  expect(restoreModule('ghost')).toBe('pomodoro');
});
it('moves between tabs with the arrow, Home and End keys', () => {
  expect(step(['a', 'b', 'c'], 'c', 'ArrowRight')).toBe('a');
  expect(step(['a', 'b', 'c'], 'a', 'ArrowLeft')).toBe('c');
  expect(step(['a', 'b', 'c'], 'b', 'End')).toBe('c');
  expect(step(['a', 'b', 'c'], 'b', 'Enter')).toBeNull();
});
```
